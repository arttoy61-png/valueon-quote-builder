# VALUEON Quote Builder

VALUEON MAKE용 제품 소싱 견적서 생성기 1차 버전입니다.

## 1차 기능
- 제품 이미지 업로드
- 수신 업체 / 견적번호 / 견적일 / 유효기간
- 제품명 / 설명 / 규격 / 옵션 / 커스텀 / MOQ
- 수량 × 단가 자동 계산
- VAT 별도 10% 또는 포함 계산
- 운송비 반영
- 최종 합계 자동 계산
- A안(제품 제안형) 실시간 A4 미리보기
- PDF 다운로드
- 수정 가능한 PPTX 다운로드

## 계산 기준
- VAT 별도: 공급가액 = 수량 × 단가, VAT = 공급가액 × 10%
- VAT 포함: 입력 단가를 VAT 포함 단가로 보고 공급가액과 VAT를 10/11, 1/11로 분리
- 최종 합계 = 상품 총액 + 운송비

## 2차 예정
- 금액 공개 / 비공개 모드
- 견적 저장 / 불러오기
- 다품목 견적
- VALUEON MAKE 연결
- VALUEON HOME 상품 등록 도구로 확장

입력 데이터와 제품 이미지는 현재 브라우저에서만 처리하며 서버에 저장하지 않습니다.
